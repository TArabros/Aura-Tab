# Nova Tab — Personal Command Center for Google Chrome (Manifest V3)

Nova Tab — это премиальное браузерное расширение нового поколения, превращающее стандартную новую вкладку Google Chrome в персонализированную операционную систему: визуальный дашборд, быстрые закладки, глобальное управление медиа и встроенный ИИ-ассистент.

---

## 🌟 Основные возможности

### 1. Главная страница (Premium Dashboard)
- **Часы и дата:** Большие минималистичные часы с датой и контекстным приветствием (*Good morning*, *Good afternoon*, *Good evening*), поддерживающим имя пользователя.
- **Умная поисковая строка:** Поиск в Google или мгновенный переход по введенному URL с плавной анимацией фокуса.
- **Адаптивный макет:** Плавное смещение и масштабирование контента при открытии боковых панелей.

### 2. Персональные ярлыки и папки (Shortcuts & Folders)
- **Добавление сайтов:** Быстрое добавление по URL с автоматическим определением названия и загрузкой favicon высокого разрешения.
- **Папки:** Создание папок для группировки сайтов и организация рабочего пространства.
- **Drag-and-Drop:** Перетаскивание ярлыков для изменения порядка и перемещения в папки.
- **Контекстное меню:** Правый клик мыши открывает меню (Редактировать, Открыть в новой вкладке, Удалить).
- **Готовые закладки:** При первом запуске сразу доступны популярные сервисы (Google, YouTube, GitHub, X, Reddit, ChatGPT, Spotify, Wikipedia).

### 3. Управление медиа в реальном времени («Сейчас играет»)
- **Автоматическое обнаружение:** Фоновый Service Worker и Content Script отслеживают воспроизведение аудио/видео во всех вкладках браузера.
- **Информация о треке:** Название трека/видео, сервис (YouTube, Spotify, SoundCloud, Apple Music и др.), имя исполнителя, обложка и анимированный индикатор воспроизведения.
- **Управление:** Кнопки «Предыдущий трек», «Воспроизведение/Пауза», «Следующий трек» и «Перейти на вкладку с медиа». Переключение треков работает на YouTube, YouTube Music, Spotify и SoundCloud; на остальных сайтах эти кнопки неактивны.
- **Мульти-сессии:** Если звук играет в нескольких вкладках, отображается выпадающий список для переключения между ними.
- **Честное отображение статуса:** Если сайт не поддерживает переключение треков или медиа не играет, интерфейс корректно информирует об этом.

### 4. Встроенный AI-ассистент (Правая выдвижная панель)
- **3 режима работы:**
  - *Hidden* — панель закрыта, доступна через кнопку в шапке или плавающую боковую кнопку.
  - *Compact* (320px) — узкий удобный сайдбар рядом с закладками.
  - *Expanded* (500px) — полноэкранный диалог для глубокой работы.
- **Потоковый вывод (Streaming):** Генерация ответов в реальном времени.
- **Форматирование:** Поддержка GitHub Flavored Markdown, списков, таблиц и блоков кода с подсветкой и кнопкой копирования в один клик.
- **Управление чатами:** Сохранение истории диалогов, создание новых чатов, удаление и очистка.
- **Поддержка любых LLM:** Готовые пресеты для OpenAI (GPT-4o / GPT-4o-mini), OpenRouter, Groq и локальных моделей через Ollama (`http://localhost:11434/v1/chat/completions`), а также любые OpenAI-совместимые API.
- **Безопасность:** Ключи API хранятся исключительно в локальном изолированном хранилище `chrome.storage.local`.

### 5. Персонализация и фоновые изображения
- **Библиотека встроенных обоев по 8 категориям:**
  - *Dark Minimal*
  - *Cyberpunk*
  - *Neon City*
  - *Space*
  - *Nature*
  - *Abstract*
  - *Anime-inspired*
  - *Glassmorphism*
- **Свои изображения:** Загрузка собственных обоев с компьютера (сохраняются локально в базе данных IndexedDB).
- **Градиенты и цвета:** Настройка градиентов с углом наклона и палитра сплошных цветов.
- **Эффекты:** Регулировка размытия фона (Blur: 0–30px), затемнения (Darkness: 0–90%) и прозрачности стеклянных панелей (Panel Opacity).
- **Темы:** Мгновенное переключение между тёмной и светлой темами.
- **Настройка сетки:** Выбор количества колонок (3–10), размера иконок (small, medium, large), отображения подписей и вертикального положения сетки (top, center, bottom).

### 6. Резервное копирование и экспорт
- Полный экспорт настроек, закладок, папок и истории диалогов в JSON-файл (Настройки → General). API-ключ и загруженные обои в файл не попадают.
- Восстановление из резервной копии в один клик.
- Сброс настроек до заводских без потери закладок, чатов и подключения AI.

## 🛠 Технический стек и архитектура

- **Chrome Extension API:** Manifest V3, Service Worker (`background.js`), Content Scripts (`content.js`), Chrome Storage API, Tabs API, Alarms API.
- **Frontend:** React 19, TypeScript, Tailwind CSS v4, Lucide Icons, React Markdown, Remark GFM.
- **Сборщик:** Vite 8 с Rollup (параллельная компиляция NewTab приложения, фонового Service Worker и Content Script).
- **Хранилище:** `chrome.storage.local` для настроек и ярлыков + `IndexedDB` для тяжелых пользовательских обоев.

## 🚀 Установка и сборка

### Шаг 1. Установка зависимостей
```bash
npm install
```

### Шаг 2. Сборка расширения
```bash
npm run build
```
После сборки в корне проекта появится папка `dist/`, содержащая полностью готовое к загрузке в браузер расширение:
- `dist/manifest.json`
- `dist/newtab.html`
- `dist/background.js`
- `dist/content.js`
- `dist/assets/`
- `dist/icons/`

### Режим разработки (Live Server)
Для разработки UI в браузере с HMR:
```bash
npm run dev
```

## 🧩 Как загрузить расширение в Google Chrome

1. Откройте Google Chrome.
2. В адресной строке перейдите по адресу:
   ```
   chrome://extensions
   ```
3. В правом верхнем углу включите переключатель **«Режим разработчика»** (*Developer mode*).
4. В левом верхнем углу нажмите кнопку **«Загрузить распакованное расширение»** (*Load unpacked*).
5. В открывшемся окне выберите папку:
   ```
   c:\projects\extension\dist
   ```
6. Нажмите **«Выбор папки»**.
7. Откройте новую вкладку в браузере (`Ctrl + T` или `Cmd + T`) — откроется ваша персонализированная страница **Nova Tab**!

## 🤖 Настройка искусственного интеллекта

1. В правом верхнем углу главной страницы нажмите на иконку ✨ (*AI Assistant*), затем на шестерёнку в шапке панели.
2. Выберите готовый пресет или укажите свои параметры:
   - **OpenAI:**
     - Endpoint: `https://api.openai.com/v1/chat/completions`
     - Model: `gpt-4o-mini` или `gpt-4o`
     - Key: ваш API-ключ `sk-...`
   - **OpenRouter:**
     - Endpoint: `https://openrouter.ai/api/v1/chat/completions`
     - Model: `deepseek/deepseek-chat` или `meta-llama/llama-3.3-70b-instruct`
   - **Groq:**
     - Endpoint: `https://api.groq.com/openai/v1/chat/completions`
     - Model: `llama-3.3-70b-versatile`
   - **Локальный Ollama (без ключа):**
     - Endpoint: `http://localhost:11434/v1/chat/completions`
     - Model: `llama3.2`
3. Нажмите **«Сохранить настройки»** и начните диалог!
